# Sklad

Papirni sklad. Začetni kapital je 1000 EUR. Tveganje na posel je največ 1% računa, velikost pride iz razdalje do stopa. Dnevna zavora je 3%. Izklop je 15% od vrha knjige. Vzvod je 1x. Živih naročil ni.

Aplikacija je na `/fund/`. Koren strani preusmeri tja. Stanje objavlja tok Paper fund na vejo `fund-data`.
